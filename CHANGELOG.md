# Changelog

## 0.1.0-beta (2026-11-02)

- Rename experimental FNX Client Repeater to FNXRepeater.
- Support standard-style card UI, collapse/expand, number/title, local mutations, pagination, RTL and dark mode.
- Accept a static subset of native Filament fields in `schema([...])` and `FNXColumn` definitions.
- Preserve deferred Livewire state and server-side JSON row validation.
- Add playground plus Node, PHP smoke and Playwright browser tests.
- Explicitly document missing native relationship and dynamic schema parity.
